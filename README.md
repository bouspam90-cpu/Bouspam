# BOUSPAM

Pake konplè sit BOUSPAM pou Cloudflare Pages, ak Supabase Auth, fonksyon peman aktivasyon, demann depo, retrè otomatik NatCash/MonCash atravè API machann PaymPlopPlop, panel administratè, referans ak jwèt.

Li `README_CLOUDFLARE.txt` pou konfigirasyon ak etap tès yo. Kouri SQL yo ki nesesè nan Supabase; mete sekrè yo sèlman nan Cloudflare Variables and Secrets.
